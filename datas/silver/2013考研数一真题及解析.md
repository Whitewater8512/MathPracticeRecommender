(1) 已知极限$\lim_{x \to 0} \frac{y - \arctan x}{x^k} = c$，其中c, k为常数，且c ≠ 0，则（ ）  
(A) $k = 2, c = -\frac{1}{2}$  
(B) $k = 2, c = \frac{1}{2}$  
(C) $k = 3, c = -\frac{1}{3}$  
(D) $k = 3, c = \frac{1}{3}$  
【答案】D  
【解析】$\lim_{x \to 0} \frac{x - \arctan x}{x^k} = \lim_{x \to 0} \frac{x - (x - \frac{1}{3}x^3 + o(x^3))}{x^k} = \lim_{x \to 0} \frac{\frac{1}{3}x^3}{x^k} = c$，∴$k = 3, c = \frac{1}{3}$  
(2) 曲面$x^2 + \cos(xy) + yz + x = 0$在点(0,1,-1)处的切平面方程为（ ）  
(A) $x - y + z = -2$  
(B) $x + y + z = 2$  
(C) $x - 2y + z = -3$  
(D) $x - y - z = 0$  
【答案】A  
【解析】设$F(x, y, z) = x^2 + \cos(xy) + yz + x$，  
则$F_x(x, y, z) = 2x - y \sin(xy) + 1 \Rightarrow F_x(0, 1, -1) = 1$；  
$F_y(x, y, z) = -x \sin(xy) + z \Rightarrow F_y(0, 1, -1) = -1$；  
$F_z(x, y, z) = y \Rightarrow F_z(0, 1, -1) = 1$，  
所以该曲面在点(0,1,-1)处的切平面方程为$x - (y - 1) + (z + 1) = 0$，  
化简得$x - y + z = -2$，选A
