当 \( m > n \) 时，有 \( r(AB) \leq \min \{ r(A), r(B) \} \leq n < m \)。（\( ABx = 0 \) 的系数矩阵的秩小于未知数的个数），故有行列式 \( |AB| = 0 \)，故应选(B)。

方法2：\( B \) 是 \( n \times m \) 矩阵，当 \( m > n \) 时，则 \( r(B) = n \)（系数矩阵的秩小于未知数的个数），方程组 \( Bx = 0 \) 必有非零解，即存在 \( x_0 \neq 0 \)，使得 \( Bx_0 = 0 \)，两边左乘 \( A \)，得 \( ABx_0 = 0 \)，即 \( ABx = 0 \) 有非零解，从而 \( |AB| = 0 \)，故选(B)。

方法3：用排除法
