解 由 dz = 2x dx - 2y dy 可知
$$z = f(x, y) = x^2 - y^2 + C,$$
再由 f(1, 1) = 2, 得 C = 2,
故 z = f(x, y) = x^2 - y^2 + 2.
令 $$\frac{\partial f}{\partial x} = 2x = 0,$$ $$\frac{\partial f}{\partial y} = -2y = 0,$$
解得驻点 (0, 0).
在椭圆 $$\frac{x^2}{4} + \frac{y^2}{4} = 1$$ 上, z = x^2 - (4 - 4x^2) + 2, 即 z = 5x^2 - 2 (-1 \leq x \leq 1),
其最大值为 $$z_{x=1} = 3,$$ 最小值为 $$z_{x=0} = -2,$$
再与 f(0, 0) = 2 比较, 可知 f(x, y) 在椭圆域 D 上的最大值为 3, 最小值为 -2.
