(20)【详解】(1) 证法一：对 $y = \sum_{n=0}^{\infty} a_n x^n$ 求一阶和二阶导数，得 $y' = \sum_{n=1}^{\infty} n a_n x^{n-1}, y'' = \sum_{n=2}^{\infty} n(n-1) a_n x^{n-2}$，代入 $y'' - 2xy' - 4y = 0$，得 $\sum_{n=2}^{\infty} n(n-1) a_n x^{n-2} - 2x \sum_{n=1}^{\infty} n a_n x^{n-1} - 4 \sum_{n=0}^{\infty} a_n x^n = 0$，即 $\sum_{n=0}^{\infty} (n+1)(n+2) a_{n+2} x^n - \sum_{n=1}^{\infty} 2n a_n x^n - \sum_{n=0}^{\infty} 4 a_n x^n = 0$，于是 $\begin{cases} 2a_2 - 4a_0 = 0 \\ (n+1)a_{n+2} - 2a_n = 0, \quad n = 1, 2, \cdots \end{cases}$，从而 $a_{n+2} = \frac{2}{n+1} a_n, n = 1, 2, \cdots$。
