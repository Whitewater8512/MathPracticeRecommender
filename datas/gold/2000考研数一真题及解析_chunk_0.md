# 2000年全国硕士研究生入学统一考试数学一试题解析

## 一、填空题

### (1) 【答案】$\frac{\pi}{4}$

【详解】
$$I = \int_{0}^{1} \sqrt{2x - x^2} \, dx = \int_{0}^{\pi/2} \sqrt{1 - (\sin t - 1)^2} \, dt$$

**解法1：用换元积分法：设$x - 1 = \sin t$，当$x = 0$时，$\sin t = -1$，所以下限取$-\frac{\pi}{2}$；当$x = 1$时，$\sin t = 0$，所以上限取$0$。**

$$I = \int_{-\pi/2}^{0} |\cos t| \cos t \, dt$$

由于在区间$[-\frac{\pi}{2}, 0]$，函数$\cos t$非负，则

$$I = \int_{0}^{\pi/2} \cos^2 t \, dt = \int_{0}^{\pi/2} \cos^2 t = \frac{\pi}{4}$$

**解法2：由于曲线$y = \sqrt{2x - x^2} = \sqrt{1 - (x - 1)^2}$是以点(1,0)为圆心，以1为半径的上半圆周，它与直线$x = 1$和$y = 0$所围图形的面积为圆面积的$\frac{1}{4}$，故答案是$\frac{\pi}{4}$。**
