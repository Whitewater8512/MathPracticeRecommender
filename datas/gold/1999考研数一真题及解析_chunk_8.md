将其标准化有：$P\left\{\frac{X + Y - 1}{\sqrt{2}} \leq \frac{1 - 1}{\sqrt{2}}\right\} = P\left\{\frac{X + Y - 1}{\sqrt{2}} \leq 0\right\} = \frac{1}{2}$（根据标准正态分布的对称性）

故B正确。

C选项：$P\{X - Y \leq 0\} = \frac{1}{2}$

将其标准化有：$P\left\{\frac{X - Y - (-1)}{\sqrt{2}} \leq \frac{0 - (-1)}{\sqrt{2}}\right\} = P\left\{\frac{X - Y + 1}{\sqrt{2}} \leq \frac{1}{\sqrt{2}}\right\} > \frac{1}{2}$，故C错。

D选项：$P\{X - Y \leq 1\} = \frac{1}{2}$

将其标准化有：$P\left\{\frac{X - Y - (-1)}{\sqrt{2}} \leq \frac{1 - (-1)}{\sqrt{2}}\right\} = P\left\{\frac{X - Y + 1}{\sqrt{2}} \leq \frac{2}{\sqrt{2}}\right\} > \frac{1}{2}$，故D错。

三、【详解】分别在$z = yf(x, y)$和$F(x, y, z) = 0$的两端对$x$求导数，得

$\frac{dz}{dx} = f(x, y) + x\left(1 + \frac{dy}{dx}\right)f'(x, y)$

$F_x' + F_y' \frac{dy}{dx} + F_z' \frac{dz}{dx} = 0$
