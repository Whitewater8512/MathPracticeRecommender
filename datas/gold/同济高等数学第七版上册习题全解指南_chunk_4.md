(6) \( x + 1 \neq k\pi + \frac{\pi}{2} (k \in \mathbb{Z}) \)，即定义域为 \(\left\{ x \mid x \in \mathbb{R} \text{ 且 } x \neq \left(k + \frac{1}{2}\right)\pi - 1, k \in \mathbb{Z} \right\}\)。

(7) \( |x - 3| \leq 1 \Rightarrow 2 \leq x \leq 4 \)，即定义域为 \([2, 4]\)。

(8) \( 3 - x \geq 0 \) 且 \( x \neq 0 \)，即定义域为 \((-\infty, 0) \cup (0, 3]\)。

(9) \( x + 1 > 0 \Rightarrow x > -1 \)，即定义域为 \((-1, +\infty)\)。

(10) \( x \neq 0 \)，即定义域为 \((-\infty, 0) \cup (0, +\infty)\)。

注 本题是求函数的自然定义域，一般方法是先写出构成所求函数的各个简单函数的定义域，再求出这些定义域的交集，即得所求定义域。下列简单函数及其定义域是经常用到的：

\( y = \frac{Q(x)}{P(x)}, P(x) \neq 0 \)

\( y = \sqrt[2]{x}, x \geq 0 \)

\( y = \log_a x, x > 0 \)
