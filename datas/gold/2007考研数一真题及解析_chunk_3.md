$\text{所以} \ln \left[1 + \frac{x + \sqrt{x}}{1-\sqrt{x}}\right] \sim \frac{x + \sqrt{x}}{1-\sqrt{x}} \sim x + \sqrt{x} = \sqrt{x} \left(\sqrt{x} + 1\right) \sim \sqrt{x}, \text{选} (B).$

方法3: $\lim_{x \to 0^+} \frac{\ln(1+x)}{\sqrt{x}} = \lim_{x \to 0^+} \left[\frac{\ln(1+x)}{\left(\sqrt{x}\right)^2}\right] = \lim_{x \to 0^+} \frac{1 - \sqrt{x}}{1 + x} \cdot \frac{1 + x}{2\sqrt{x}}$

$= \lim_{x \to 0^+} \frac{1 - \sqrt{x} - \sqrt{x} + \frac{1}{2\sqrt{x}}(1 + x)}{1 + x} = \lim_{x \to 0^+} \frac{2\sqrt{x} \left(2\sqrt{x} + 1 - x\right)}{(1 + x)(1 - \sqrt{x})}$

$\text{设} \frac{2\sqrt{x} \left(2\sqrt{x} + 1 - x\right)}{(1 + x)(1 - \sqrt{x})} = \frac{A}{1 + x} + \frac{B}{1 - \sqrt{x}}, \text{则} A(1 - \sqrt{x}) + B(1 + x) = 4x + 2\sqrt{x} - 2x\sqrt{x}$
