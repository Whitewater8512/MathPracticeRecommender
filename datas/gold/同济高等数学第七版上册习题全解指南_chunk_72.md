### 4. 设 $f(x)$ 的定义域是 $[0, 1]$，求下列函数的定义域：

#### (1) $f(e^x)$；
#### (2) $f(\ln x)$；
#### (3) $f(\arctan x)$；
#### (4) $f(\cos x)$。

解

#### (1) 因为 $0 \leq e^x \leq 1$，所以 $x \leq 0$，即函数 $f(e^x)$ 的定义域为 $(-\infty, 0]$。

#### (2) 因为 $0 \leq \ln x \leq 1$，所以 $1 \leq x \leq e$，即函数 $f(\ln x)$ 的定义域为 $[1, e]$。

#### (3) 因为 $0 \leq \arctan x \leq 1$，所以 $0 \leq x \leq \tan 1$，即函数 $f(\arctan x)$ 的定义域为 $[0, \tan 1]$。

#### (4) 因为 $0 \leq \cos x \leq 1$，所以 $2n\pi - \frac{\pi}{2} \leq x \leq 2n\pi + \frac{\pi}{2}, n \in \mathbb{Z}$，即函数 $f(\cos x)$ 的定义域为 $[2n\pi - \frac{\pi}{2}, 2n\pi + \frac{\pi}{2}], n \in \mathbb{Z}$。
