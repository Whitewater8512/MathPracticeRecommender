## (3) 【答案】\(y = \sqrt{x + 1}\)

### 【详解】方法1：这是属于缺 \(x\) 的 \(y'' = f(y, y')\) 类型。令 \(y' = p\)，\(y'' = \frac{dp}{dx} = \frac{dp}{dy} \frac{dy}{dx} = p \frac{dp}{dy}\)。

原方程 \(yy'' + y'^2 = 0\) 化为 \(yp \frac{dp}{dy} + p^2 = 0\)，得
\[
p = 0 \quad \text{或} \quad \frac{dp}{dy} + p = 0
\]
\[
p = 0, \quad \text{即} \quad \frac{dy}{dx} = 0, \quad \text{不满足初始条件} \quad \left. y' \right|_{x=0} = \frac{1}{2}, \quad \text{弃之；所以} \quad p \neq 0
\]
所以，\(y \frac{dp}{dy} + p = 0\)，分离变量得 \(\frac{dy}{y} = -\frac{dp}{p}\)，解之得 \(p = \frac{C_1}{y}\)。即 \(\frac{dy}{dx} = \frac{C_1}{y}\)。

由初始条件 \(\left. y \right|_{x=0} = 1\)，\(\left. y' \right|_{x=0} = \frac{1}{2}\)，可将 \(C_1\) 先定出来：\(\frac{1}{2} = \frac{C_1}{1}\)，\(C_1 = \frac{1}{2}\)。于是得
\[
\frac{dy}{dx} = \frac{1}{2y}
