# §4. 幂级数

## 1. 函数项级数的一般概念

(1) 函数项级数的定义 设给定一个定义在区间 \([a, b]\) 上的函数列

$$u_1(x), u_2(x), \ldots, u_n(x), \ldots,$$

则式子

$$u_1(x) + u_2(x) + \cdots + u_n(x) + \cdots,$$

叫做函数项级数。

(2) 函数项级数的收敛域 对于区间 \([a, b]\) 上的每一个值 \(x_0\)，级数

$$u_1(x_0) + u_2(x_0) + \cdots + u_n(x_0) + \cdots,$$

如果收敛，则称 \(x_0\) 是级数①的收敛点；如果发散，则称 \(x_0\) 是级数①的发散点，①所有收敛点的全体称为函数项级数①的收敛域。

(3) 函数项级数的和函数 对于收敛域内的任一点 \(x\)，级数①都有一个确定的和

$$S(x) = \sum_{n=1}^{\infty} u_n(x),$$

\(S(x)\) 是定义在收敛域上的函数，称为级数①的和函数。

## 2. 幂级数及其收敛域

(1) 幂级数的定义 形如

$$a_0 + a_1(x - x_0) + a_2(x - x_0)^2 + \cdots + a_n(x - x_0)^n + \cdots,$$

或

$$a_0 + a_1 x + a_2 x^2 + \cdots + a_n x^n + \cdots,$$

的级数称为幂级数。
