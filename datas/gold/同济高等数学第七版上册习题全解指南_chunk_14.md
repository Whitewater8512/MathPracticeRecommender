(4) \(\begin{cases} 0 \leq x + a \leq 1, \\ 0 \leq x - a \leq 1 \end{cases} \Rightarrow \text{当 } 0 < a \leq \frac{1}{2} \text{时, } x \in [a, 1-a]；\text{当 } a > \frac{1}{2} \text{时, 定义域为 } \varnothing \)。
