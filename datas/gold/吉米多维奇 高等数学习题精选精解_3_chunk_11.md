(3) 极值存在的充分条件 设函数 $z = f(x, y)$ 在点 $P_0(x_0, y_0)$ 的某邻域内具有二阶连续偏导数，且 $f_x'(x_0, y_0) = 0, f_y'(x_0, y_0) = 0$，记 $A = f_{xx}''(x_0, y_0), B = f_{xy}''(x_0, y_0), C = f_{yy}''(x_0, y_0)$.

① 若 $B^2 - AC < 0$，则 $f(x_0, y_0)$ 是极值，当 $A < 0$ 时，$f(x_0, y_0)$ 是极大值，当 $A > 0$ 时，$f(x_0, y_0)$ 是极小值.

② 若 $B^2 - AC > 0$，则 $f(x_0, y_0)$ 不是极值.

③ 若 $B^2 - AC = 0$，则 $f(x_0, y_0)$ 可能是极值，也可能不是极值.

2. 条件极值、拉格朗日乘数法 函数 $u = f(x, y)$ 在附加条件 $\varphi(x, y) = 0$ 下的极值称为条件极值.

拉格朗日乘数法 求条件极值时，可作函数

$F(x, y) = f(x, y) + \lambda \varphi(x, y)$

其中，$\lambda$ 是某一常数，则点 $(x, y)$ 是极值点的必要条件为

$\begin{cases}
F_x'(x, y) = f_x'(x, y) + \lambda \varphi_x'(x, y) = 0 \\
F_y'(x, y) = f_y'(x, y) + \lambda \varphi_y'(x, y) = 0 \\
\varphi(x, y) = 0
\end{cases}$

从上述方程组中解出 $x, y$ 及 $\lambda$ 的值，则点 $(x, y)$ 就可能是条件极值的极值点.
