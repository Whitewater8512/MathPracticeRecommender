（23）（本题满分 11 分）某工程师为了解一台天平的精度，用该天平对一物体的质量做 n 次测量，该物体的质量 μ 是已知的，设 n 次测量结果 X_1, X_2, ..., X_n 相互独立且均服从正态分布 N(μ, σ^2)。该工程师记录的是 n 次测量的绝对误差 Z_i = |X_i - μ| (i = 1,2, ..., n)，利用 Z_1, Z_2, ..., Z_n 估计 σ。

(I) 求 Z_i 的概率密度；

(II) 利用一阶矩求 σ 的矩估计量；

（III）最大似然估计：σ = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (X_i - μ)^2}

【答案】
(I) f_{Z_i}(z) = \begin{cases} 
\frac{2}{\sqrt{2π}σ} e^{-\frac{z^2}{2σ^2}}, & z > 0 \\
0, & 其他 
\end{cases}

(II) 矩估计：σ = \frac{1}{n} \sqrt{\frac{π}{2}} \sum_{i=1}^{n} |X_i - μ|

（III）最大似然估计：σ = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (X_i - μ)^2}

【解析】(I) F_{Z_i}(z) = P(Z_i ≤ z) = P(|X_i - μ| ≤ z)
