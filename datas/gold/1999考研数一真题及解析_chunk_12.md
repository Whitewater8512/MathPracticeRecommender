证法2：先对要证的不等式作适当变形，当 $x = 1$ 时，原不等式显然成立；

当 $0 < x < 1$ 时，原不等式等价于 $\ln x \leq \frac{x - 1}{x + 1}$；

当 $1 < x < +\infty$ 时，原不等式等价于 $\ln x \geq \frac{x - 1}{x + 1}$；

令

$$f(x) = \ln x - \frac{x - 1}{x + 1}$$

则

$$f'(x) = \frac{1}{x} - \frac{2}{(x + 1)^2} = \frac{x^2 + 1}{x(x + 1)^2} > 0 (x > 0)$$

又因为 $f(1) = 0$，利用函数单调性可知

当 $0 < x < 1$ 时，$f(x) < 0$，即 $\ln x < \frac{x - 1}{x + 1}$；当 $1 < x < +\infty$ 时，$f(x) > 0$，即 $\ln x > \frac{x - 1}{x + 1}$；

综上所述，当 $x > 0$ 时，$(x^2 - 1)\ln x \geq (x - 1)^2$.
