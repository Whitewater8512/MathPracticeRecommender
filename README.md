# 📐 基于 BKT 用户画像建模与知识图谱驱动的数学推题系统
> **课程实践作业：智能推荐系统 (Intelligent Recommendation Systems)**

## 📖 项目简介
本项目致力于打造一个**自适应教育推荐系统（Adaptive Educational Recommendation System）**。
与传统电商“投其所好”的协同过滤推荐不同，本系统旨在实现“查漏补缺”。通过引入教育数据挖掘领域的认知诊断技术，系统能够动态追踪学生的学习状态，并依托知识图谱实现精准的个性化题目分发。

## ✨ 核心算法与特性
本项目完整实现了推荐系统“画像建模 -> 策略路由 -> 内容召回”的标准流水线：
* **动态用户画像 (User Profiling)：** 底层基于贝叶斯知识追踪（**BKT**）模型，通过分析用户的历史答题正误率、失误率与猜对率，实时推断用户对特定知识点的掌握概率。
* **知识图谱路由 (Graph-based Routing)：** 当检测到用户能力薄弱时，系统不会盲目推题，而是利用 NetworkX 图谱引擎结合 PageRank 与余弦相似度计算 Attention Score，自动向“前置基础知识点”进行降维推荐。
* **自适应物料过滤 (Item Filtering)：** 基于曝光过滤（剔除已做对的题目）和动态难度匹配机制，从本地 SQLite 题库中精准召回处于用户“最近发展区”的题目。
* **大模型生成式推荐 (Generative Recommendation)：** 解决题库“冷启动”与物料枯竭问题。结合 RAG 技术与云端大模型，系统可实时生成高质量数学解析，并依托 Redis 缓冲池实现异步队列补给。

## 🛠️ 技术栈
* **前端交互：** Streamlit
* **推荐引擎：** BKT (贝叶斯推断), 动态图谱路由算法
* **数据工程：** PyMuPDF (视觉解析), NetworkX, Pandas
* **模型与存储：** ChromaDB (向量库), Redis (异步队列), SQLite, LLM API
